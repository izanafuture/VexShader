# VEX RTX 5.0 — Evade Edition

Клиентский Luau-скрипт с интерфейсом и графическими эффектами Roblox. Содержит **8 пресетов**: RTX+, Realism, Neon, Cinema, Sunset, Storm, Dream и FPS.

**Это RTX-style визуализация, а не аппаратный ray tracing.** Настоящие зеркальные отражения, SSR, трассировка пути и RTGI с обычным Luau API недоступны. Экспериментальная вкладка RTX LAB использует ViewportFrame и локальные копии объектов; её отражения могут быть искажены, отсутствовать или снижать FPS.

## Запуск

Скопируйте в строку Lua-executor (например, Xeno) в Roblox:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/izanafuture/VexShader/main/VEX_RTX.lua"))()
```

Работает **только после загрузки `VEX_RTX.lua` в корень ветки `main`**. Не требует модулей, токенов GitHub, ключей или доступа к файловой системе executor. Код открытый и не скачивает дополнительных скриптов.

## Управление

- **RightShift** — показать/скрыть GUI.
- **F7** — включить/выключить VEX-эффекты.
- **X** в окне — выгрузить VEX RTX и попытаться вернуть изменённые свойства.
- **LOOK** — пресеты и цветокоррекция.
- **WORLD** — освещение, глянцевые поверхности, атмосфера и облака.
- **RTX LAB** — экспериментальный ViewportFrame-эффект отражения и raycast-подсветка.

## Первая публикация на GitHub

1. Откройте https://github.com/izanafuture/VexShader
2. В пустом репозитории нажмите **uploading an existing file** (или **Add file → Upload files**).
3. Перетащите **VEX_RTX.lua** и **README.md** в окно браузера.
4. Убедитесь, что выбрана ветка **main** и файлы находятся в **корне репозитория**, а не внутри папки.
5. Нажмите **Commit changes**. Теперь строка запуска выше загрузит текущую версию.

## Обновление VEX RTX

Откройте файл `VEX_RTX.lua` на GitHub и нажмите значок карандаша **Edit this file**, замените код новой версией и нажмите **Commit changes**. Прежний загрузчик останется актуальным. Для доступа к конкретной неизменяемой версии используйте в Raw-ссылке SHA коммита вместо `main`.

## Безопасность и совместимость

Скрипт не выполняет HTTP-запросов. HTTP вызывается только однострочным загрузчиком GitHub. Все визуальные изменения выполняются локально; отдельные свойства освещения могут быть перезаписаны самой игрой. Использование сторонних executors может нарушать правила Roblox. Проверяйте содержимое файла перед запуском и перед обновлениями.
